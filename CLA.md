# Loci Contributor License Agreement

Adapted from the Apache Software Foundation Individual CLA v2.0 for a
single-owner project. Plain-language summary first; the agreement itself is
below and is what actually binds.

## Why this exists

Loci is released under the [PolyForm Noncommercial 1.0.0](LICENSE) licence.
Noncommercial use is free for everyone; commercial use needs a separate licence
from the owner.

That only works if the owner holds rights broad enough to grant one. Without
this agreement, a contribution arrives licensed under PolyForm Noncommercial
itself, which means the project would hold only *noncommercial* rights to part
of its own code and could no longer license the whole of it commercially. One
merged pull request would quietly remove that option, for good.

This agreement fixes that, and keeps the licence itself changeable later. If the
project ever moves to AGPL, MIT, or a dual licence, it can do so without
tracking down every past contributor.
