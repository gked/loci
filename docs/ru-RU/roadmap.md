# Статус и дорожная карта

## Статус проекта

Работа в процессе, и личная. Ядром пользуются каждый день; края неровные. Что
это значит конкретно:

| Область | Состояние |
|---|---|
| Формат хранилища, онтология, реестры | Стабильно, в ежедневном использовании |
| MCP-сервер и навыки | Стабильно, в ежедневном использовании |
| Установка из PyPI / релизного wheel | Стабильно, в ежедневном использовании |
| Установка из чекаута (`setup.py`) | Стабильно |
| Веб-интерфейс | В ежедневном использовании, только чтение. Редактирования пока нет |
| Набор тестов (модульные + браузерные e2e) | Запускается при каждом push и PR |
| Упаковка и релизы | `make release` создаёт тег; CI собирает wheel и публикует его в PyPI и в GitHub Release |
| Синхронизация rclone | **Частично.** Только ручной скрипт, без расписания и обработки конфликтов, без тестов |

Ничего не объявлено устаревшим и не заброшено; слабые места просто не
закончены. Каждое из них также помечено там, где описано в документации, так
что помнить эту таблицу не нужно.

## Дорожная карта

`[~]` отмечает то, что существует и работает, но не закончено или плохо протестировано.

- [x] Базовая структура хранилища и схема
- [x] Инструменты `vault_init`, `uid_generator`, `slug`, `write_file`
- [x] MCP-сервер: транспорт stdio, интеграция с Claude Code / Claude Desktop
- [x] Операции patch и delete
- [x] Словарь полей: авторитетная схема в мета-файлах хранилища, навык читает её во время выполнения

- [~] Обёртка rclone: ручной скрипт `push` / `pull` / `bisync`. Без расписания, без обработки конфликтов, без тестов
