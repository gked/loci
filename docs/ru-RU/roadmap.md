# Статус и дорожная карта

## Статус проекта

Проект в работе, и личный. Ядром пользуются каждый день, края неровные. Что
это значит на практике:

| Область | Состояние |
|---|---|
| Формат хранилища, онтология, реестры | Стабильно, в ежедневном использовании |
| MCP-сервер и навыки | Стабильно, в ежедневном использовании |
| Установка из PyPI / релизного wheel | Стабильно, в ежедневном использовании |
| Установка из репозитория (`setup.py`) | Стабильно |
| Веб-интерфейс | В ежедневном использовании, только чтение. Редактирования пока нет |
| Набор тестов (модульные + браузерные e2e) | Запускается при каждом push и PR |
| Упаковка и релизы | `make release` ставит тег; CI собирает wheel и публикует его в PyPI и в GitHub Release |
| Синхронизация rclone | **Частично.** Только ручной скрипт: без расписания, без обработки конфликтов, без тестов |

Ничего не объявлено устаревшим и ничего не заброшено — просто часть вещей не
доделана. Каждая такая вещь отмечена и в документации, так что запоминать эту
таблицу не обязательно.

## Дорожная карта
