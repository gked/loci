# loci-ingest-directory — your additions

Loci appends this file to the `loci-ingest-directory` skill (the one that catalogues a directory into the vault)
every time the skill is read. Write your own rules here in plain prose:
preferences, defaults, exceptions, house conventions. Keep each one short and
concrete — the model follows them verbatim. Ask Claude to add one ("from now on, …")
and it lands here via `write_skill`.

Where this file disagrees with the packaged procedure, this file wins — except
under headings marked 🔒 in the procedure, which hold no matter what is written
here.
