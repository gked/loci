# Outer Shell — UI Kit

The marketing/identity surface for Loci. Where the project meets the world: splash plate, install flow chrome, README plates, slide title cards.

**Register**: classical antiquity. Ivory paper, ink, doubled hairline frames, Roman numerals, small caps, Latin abbreviations, the seal.

**When to use**: anything *outside* the vault — landing pages, splash, install screens, slide title cards, README plates, error pages that face new users.

**Components**

- `Plate.jsx` — framed plate with doubled hairline border (the dominant container)
- `Wordmark.jsx`, `Monogram.jsx`, `Seal.jsx` — brand marks
- `MeanderRule.jsx` — Roman fret divider
- `Button.jsx` — outer-shell button (terracotta primary, ink secondary, no radius)
- `SmallCaps.jsx`, `RomanNumeral.jsx`, `DropCap.jsx` — type primitives
- `SectionHeader.jsx` — Roman numeral marker + small-caps overline + title

Open `index.html` to see a splash composition.
